
  # Smart Home App Design

This is a code bundle for Smart Home App Design. The original project is available at https://www.figma.com/design/3ScsDAmvmMqG65c2ijWU66/Smart-Home-App-Design.

## Running the code

```bash
cd FE
npm install
npm run dev
```

Open http://localhost:5173 in browser. Use **DevTools → Toggle device toolbar** (Ctrl+Shift+M) for mobile view.
